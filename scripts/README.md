# scripts/ — служебные скрипты

Запуск — `bun` (TypeScript) или `node --env-file-if-exists=.env.local` (mjs); точные
команды — в шапке каждого файла и в корневом README.

## Демо-постановка и проверка нейроконтурa

| Скрипт | Назначение |
|---|---|
| `aemz-demo-setup.ts` | демо-постановка: экипаж победителю Z-1048, загрузка реальных сканов как PENDING |
| `aemz-reset-awarded.ts` | вернуть Z-1048 в AWARDED — чтобы у перевозчика была кнопка «Отправить на проверку» |
| `aemz-verdicts.ts` | показать вердикты автопроверки заявки Z-1048 |
| `aemz-db-check.ts` | диагностика: заявки на этапах проверки и их документы |
| `aemz-e2e.py` | E2E-проверка нейроконтурa без браузера: скан → платформа → шлюз → туннель → нейросеть, с замером времени |

## Сиды и разовые переносы данных

| Скрипт | Назначение |
|---|---|
| `seed-users.ts` | учётные записи всех ролей (идемпотентно; `bun run auth:seed`) |
| `oneoff-cargo.ts` | разовый: грузы существующих заявок → номенклатура АЭМЗ |
| `oneoff-nomenclature2.ts` | разовый: чистка номенклатуры и типов ТС (история Task 33) |
| `demo-etrn.mjs` | демо-рейс для показа ЭТрН через Диадок (`bun run demo:etrn`) |

## Инфраструктура и интеграции

| Скрипт | Назначение |
|---|---|
| `daemonize.py` | двойной fork: запуск dev-сервера как демона, переживающего закрытие терминала |
| `diadoc-check.mjs` | проверка подключения к Диадоку без отправок (`bun run diadoc:check`) |
| `github-connect.sh` | подключение GitHub-репозитория к проекту |
