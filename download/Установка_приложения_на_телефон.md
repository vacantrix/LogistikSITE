# Установка приложения водителя «АЗМЗ Логистика» на личный телефон (тест)

Дата: 11.11.2026 · Версия: **0.2.0-pilot** (versionCode 2) — настоящий APK,
собран и проверен. Android 8.0+.

---

## Путь 1 — скачать готовый APK (главный)

APK уже собран. Два способа достать его:

**Через кнопку на сайте.** Открой на телефоне ссылку предпросмотра из чата
(`https://preview-….space-z.ai`) и нажми оранжевую кнопку **«Установить
приложение»** — файл `azmz-driver.apk` скачается в «Загрузки». То же самое
делает кнопка в «Настройках» веб-версии.

**Из файлов чата.** Файл `АЗМЗ-Логистика-водитель-v0.2.0.apk` лежит в выдаче
проекта (можно перекинуть на телефон по кабелю/в мессенджер).

### Установка (4 шага)

1. Открой скачанный файл (уведомление «Загрузка завершена» или папка «Загрузки»).
2. Android спросит разрешение: **«Разрешить установку из этого источника»** —
   разреши (это твой браузер/файловый менеджер, не взлом).
3. Нажми **«Установить»** → **«Открыть»**.
4. При первом запуске разреши **доступ к местоположению** — карта построит
   маршрут от твоей позиции.

### Что увидишь

- Полноэкранный режим: никаких времени/зарядки/надписей сверху — только карта.
  Шторку уведомлений вызывает свайп от самого верхнего края.
- Внизу тёмно-синяя панель: **Карта · Рейс · История · Офис**.
- Данные подтянутся сами (демо-сервер этой сессии): заявка **ЗК-2026/1067**
  Абинск, пл. АЗМЗ → Новороссийск, причал 27, водитель Иванов С.П.
- Карта: твоя позиция — оранжевая точка; маршрут до точки выгрузки — оранжевая
  линия, варианты поездки — серые пунктиром; отклонился от маршрута — он
  перестроится (плашка «Маршрут перестроен»).
- «История»: потяни список вниз — принудительная синхронизация.
- Кнопка «Пометка» — пометки «водители для водителей» (яма/ремонт/ДПС…).

Удаление: долгое нажатие на иконку → «Удалить».

## Путь 2 — PWA (веб-версия, вторично)

Веб-версия осталась для быстрой проверки идей в браузере. Chrome на Android:
меню **⋮** → «Установить приложение». Ограничения PWA, о которых ты писал:
время и зарядка сверху — это системная статус-строка, браузер физически не
может её скрыть; поэтому полноэкранный режим — только в APK (Путь 1).
Кнопка «Установить приложение» на сайте теперь скачивает **APK**, а не PWA.

## Пересборка APK (когда изменишь код)

Вариант А — без своего компьютера: `azmz-karkas.zip` → GitHub → Actions →
«Android APK» → Download artifact (workflow внутри архива, README §14).

Вариант Б — локально: JDK 17 + Android SDK, в папке `android`:
`gradle assembleDebug`. Версию меняй в `android/app/build.gradle.kts`
(`versionCode`/`versionName`), перед боевым пилотом — собственная подпись.

## Связка с платформой «Контур 1С»

Адрес бэкенда — в `android/.../core/sync/AppGraph.kt` → `DEFAULT_BASE_URL`.
Сейчас там демо-сервер этой сессии. Для 1С-платформы (порт 3001) подставь
адрес стенда и пересобери. Контракт синхронизации (pull/push/marks,
`X-Driver-Id`) — общий с веб-версией и описан в HANDOFF-пакете платформы.
