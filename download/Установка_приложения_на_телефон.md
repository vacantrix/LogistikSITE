# Установка приложения водителя «АЭМЗ Логистика» на телефон (пилот)

Дата: 18.11.2026 · Версия: **0.2.1-pilot** (versionCode 3) · Android 8.0+.

## Что нового в 0.2.1

- Индикатор связи больше не показывает ложный офлайн: при старте —
  «Проверка связи…», затем зелёный **«На связи»**.
- Маршрут строится через собственный прокси `vacantrix.ru/osrm` (публичный
  OSRM остаётся запасным), плюс резервный маршрут по сохранённой геометрии
  рейса — плашка «Маршрут недоступен офлайн» больше не появляется.
- Официальный логотип АЭМЗ в приложении и на иконке.

## Путь 1 — скачать готовый APK (главный)

Прямая ссылка:

**https://vacantrix.ru/dl/Drivemobile.apk**

Та же кнопка **«Установить приложение»** есть на сайте водителя и в
«Настройках» веб-версии — она скачивает этот же APK.

### Важно: подпись сменилась

Если на телефоне уже стоит 0.2.0 или более ранняя сборка — **удали её перед
установкой** (долгое нажатие на иконку → «Удалить»). Android не устанавливает
обновление поверх приложения с другой подписью. Дальнейшие обновления
0.2.1+ ставятся поверх без удаления.

### Установка (4 шага)

1. Открой скачанный файл (уведомление «Загрузка завершена» или папка «Загрузки»).
2. Android спросит разрешение: **«Разрешить установку из этого источника»** —
   разреши (это твой браузер/файловый менеджер, не взлом).
3. Нажми **«Установить»** → **«Открыть»**.
4. При первом запуске разреши **доступ к местоположению** — карта построит
   маршрут от твоей позиции.

### Что увидишь

- Полноэкранный режим: никаких времени/зарядки/надписей сверху — только карта.
  Шторку уведомлений вызывает свайп от самого верхнего края.
- Внизу тёмно-синяя панель: **Карта · Рейс · История · Офис**.
- Статус связи — чип вверху: жёлтый «Проверка связи…», зелёный **«На связи»**.
  Если интернет реально пропал — красный «Нет связи, в очереди: N»; данные
  копятся локально и уходят автоматически при восстановлении.
- Данные подтянутся сами (демо-сервер): заявка **ЗК-2026/1067**
  Абинск, пл. АЭМЗ → Новороссийск, причал 27, водитель Иванов С.П.
- Карта: твоя позиция — оранжевая точка; маршрут до точки выгрузки — оранжевая
  линия, варианты поездки — серые пунктиром; отклонился от маршрута — он
  перестроится (плашка «Маршрут перестроен»).
- «История»: потяни список вниз — принудительная синхронизация.
- Кнопка «Пометка» — пометки «водители для водителей» (яма/ремонт/ДПС…).

Удаление: долгое нажатие на иконку → «Удалить».

## Путь 2 — PWA (веб-версия, вторично)

Веб-версия осталась для быстрой проверки идей в браузере. Chrome на Android:
меню **⋮** → «Установить приложение». Ограничения PWA: время и зарядка сверху —
это системная статус-строка, браузер физически не может её скрыть; поэтому
полноэкранный режим — только в APK (Путь 1). Кнопка «Установить приложение» на
сайте теперь скачивает **APK**, а не PWA.

## Пересборка APK (когда изменишь код)

Вариант А — без своего компьютера: `azmz-karkas.zip` → GitHub → Actions →
«Android APK» → Download artifact (workflow внутри архива, README §14).

Вариант Б — локально на этом компьютере (всё уже развёрнуто):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\AUSU\android-build\build-apk.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\AUSU\android-build\publish-apk.ps1
```

`build-apk.ps1` собирает `app-debug.apk` (JDK 17 + Android SDK 34 + Gradle 8.9,
зеркала Aliyun для скорости), `publish-apk.ps1` раскладывает его во все точки
раздачи, включая `https://vacantrix.ru/dl/Drivemobile.apk`.

Версию меняй в `android/app/build.gradle.kts` (`versionCode`/`versionName`).
Пилотный ключ подписи — `C:\Users\AUSU\android-build\signing\azmz-pilot.jks`
(пароли в `keystore.properties` рядом). **Не теряй его**: обновления поверх
установленного приложения возможны только с той же подписью.

## Связка с платформой «Контур 1С»

Адрес бэкенда — в `android/.../core/sync/AppGraph.kt` → `DEFAULT_BASE_URL`
(сейчас `https://vacantrix.ru/api/driver/v1/`). Контракт синхронизации
(pull/push/marks, `X-Driver-Id`) — общий с веб-версией и описан в HANDOFF-пакете
платформы.
