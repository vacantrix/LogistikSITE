# Установка приложения водителя «АЗМЗ Логистика» на личный телефон (тест)

Дата: 11.11.2026 · Версия: демо/каркас (v0.1.0-karkas)

Два пути. **Путь 1 (PWA)** — установить веб-версию прямо с сайта: одна минута,
ничего собирать не нужно, работает и на Android, и на iPhone. **Путь 2 (APK)** —
нативное Android-приложение из каркаса: APK собирается бесплатно в облаке
GitHub Actions, без Android Studio.

---

## Путь 1 — PWA: установить за минуту (рекомендую начать с него)

Веб-версия приложения оформлена как PWA: ставится с сайта как обычное
приложение — своя иконка на домашнем экране, полноэкранный режим без адресной
строки, оболочка кэшируется service worker'ом (обновляется при каждом открытии,
переустанавливать не надо).

### Android (Chrome)

1. Открой в **Chrome** на телефоне ссылку предпросмотра проекта — она приходит
   в чате с ассистентом (формат `https://preview-….space-z.ai`).
2. Меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).
3. Подтверди — на домашнем экране появится иконка: оранжевый квадрат с галочкой
   на тёмно-синем фоне.
4. Запуск — как у обычного приложения, в полноэкранном режиме.

### iPhone (только Safari)

1. Открой ссылку в **Safari** (iOS разрешает установку PWA только из Safari).
2. Кнопка **«Поделиться»** → **«На экран „Домой“»** → **«Добавить»**.

### Что учесть

- Первый запуск требует сети — оболочка и иконки кэшируются, дальше откроется
  и без сети (данные — через API: для полного теста нужен доступный сервер).
- Это тот же код демо: карта, рейс Z-1067, пометки, заявки, история.
- Удаление: долгое нажатие на иконку → «Удалить приложение».

## Путь 2 — APK: нативное Android-приложение из каркаса

APK собирается в облаке GitHub Actions — бесплатный тариф, локальный Android
SDK не нужен. В каркасе уже лежит workflow `.github/workflows/android-apk.yml`
и фирменные иконки (`mipmap-*`, adaptive-icon).

### Шаг 1. Скачать каркас

Файл `azmz-karkas.zip` (обновлён 11.11.2026: внутри иконка + workflow) —
из папки выдачи, распаковать.

### Шаг 2. Залить на GitHub

Вариант А — через git (надёжно, попадут и скрытые папки):

```bash
cd azmz-karkas
git init -b main
git add .
git commit -m "АЗМЗ Логистика: каркас приложения водителя"
# создай пустой репозиторий на github.com и подставь ссылку:
git remote add origin https://github.com/<логин>/azmz-driver.git
git push -u origin main
```

Вариант Б — через браузер: github.com → **New repository** → после создания
кнопка **«uploading an existing file»** → перетащить содержимое папки каркаса
**вместе со скрытой папкой `.github`** (drag&drop папок в браузере её
подхватывает; проверь после загрузки, что в репозитории есть
`.github/workflows/android-apk.yml`).

### Шаг 3. Запустить сборку

Пуш в `main` запускает сборку автоматически, либо вкладка **Actions** →
«Android APK» → **Run workflow**. Через 5–10 минут в забеге появится артефакт
**azmz-driver-apk** (`app-debug.apk`, подписан debug-ключом — ставится на любой
телефон).

Первый прогон может упасть на компиляции каркаса (версии зависимостей в
`gradle/libs.versions.toml` помечены как ориентировочные) — по логу Actions
ошибка правится точечно, потом сборка зелёная всегда.

### Шаг 4. Скачать и установить на телефон

1. Скачай артефакт на компьютер (zip), распакуй — внутри `app-debug.apk`.
2. Передай файл на телефон — Telegram «Избранное», почта, облако или USB.
3. На телефоне открой файл → Android спросит **«Разрешить установку из этого
   источника»** → разрешить → **Установить**.
   (Если блокирует: Настройки → Безопасность → Установка приложений из
   неизвестных источников → разрешить для того приложения, которым открыл APK.)
4. Появится приложение **«АЗМЗ Логистика»** с фирменной иконкой.

### Шаг 5. Куда смотрит нативное приложение

Каркас ожидает бэкенд Spring Boot (порт 8080) и по умолчанию ходит на
`http://10.0.2.2:8080/api/driver/v1/` — это адрес «localhost» для эмулятора.
Для телефона: запусти бэкенд (`docker compose up -d postgres && cd backend &&
./gradlew bootRun --args='--spring.profiles.active=demo'`), узнай IP компьютера
в Wi-Fi сети и поменяй `AppGraph.DEFAULT_BASE_URL` на
`http://<IP-компьютера>:8080/api/driver/v1/`, затем пересобери APK (Шаг 3
повторно). Для веб-версии (Путь 1) ничего менять не нужно.

## Путь 3 — Android Studio (если будешь дорабатывать)

1. Установи Android Studio (Ostrich+), открой папку `android/` как проект.
2. Телефон: Настройки → О телефоне → 7 раз тапнуть «Номер сборки» →
   «Для разработчиков» → включить **Отладку по USB** → подключить кабелем.
3. В студии выбрать устройство → **Run ▶** — установит сборку с отладкой.

## Связка с платформой «Контур 1С» (эмулятор 1С)

Платформа «Контур 1С» поднимается на порту 3001 и отдаёт те же контракты, что
потребляет приложение. После того как сессия-разработчик выдаст HANDOFF-пакет
(см. `ПРОМТ_передача_результатов_1С.md`), приложение водителя подключается к
нему без правок клиента: `/api/1c/orders` и синхро-каналы переключаются на
адрес платформы переменной окружения `KONTUR_1C_URL` (раздел 10.2 ТЗ).

## Чек-лист минимального теста на телефоне

- [ ] Иконка ставится на домашний экран, имя «АЗМЗ Логистика».
- [ ] Приложение открывается в полноэкранном режиме, вкладки переключаются.
- [ ] Карта 2ГИС загружается в мобильной сети (не только в Wi-Fi).
- [ ] Рейс Z-1067: карточки событий, «Взять заявку», предрейсовые фото.
- [ ] Авиарежим: приложение не падает, появляется бейдж «Офлайн».
- [ ] (APK) После установки иконка лаунчера не «пустая», adaptive-иконка
      обрезается корректно на круге.
