Добавь в платформу «Контур 1С» функцию построения маршрута заявки через Яндекс.Карты со вставкой ссылки. Приложение водителя (порт 3000, версия 0.8.0) уже готово принимать этот маршрут — твоя часть только на стороне платформы (порт 3001).

## Сценарий (как договорились с заказчиком)

1. Диспетчер открывает заявку (RequestsScreen / экран диспетчерской) и жмёт кнопку **«Построить маршрут»**.
2. Открывается Яндекс.Карты (в новой вкладке) с предзаполненными точками заявки — диспетчер правит маршрут там, добавляет промежуточные точки и жмёт **«Поделиться» → «Ссылка» → копирует**.
3. Диспетчер возвращается в платформу, вставляет ссылку в поле **«Ссылка на маршрут (Яндекс.Карты)»**, жмёт **«Разобрать ссылку»** — программа разбирает точки из ссылки и показывает «Маршрут: N точек, M км (по прямой)».
4. Заявка сохраняется со ссылкой и точками. После назначения водителю приложение водителя строит рейс по этим точкам.

## Формат ссылки Яндекс.Карт (что разбирать)

```
https://yandex.ru/maps/?rtext=55.753930%2C37.620795~59.931123%2C30.360932&rtt=auto&z=7
```

- `rtext` — точки маршрута через `~`, каждая — `широтa,долгота` (после `decodeURIComponent`; запятые могут быть закодированы как `%2C`). От 2 точек и больше (промежуточные — тоже в этой же строке).
- `rtt` — тип маршрута: `auto` (авто) | `mt` (транспорт) | `pd` (пешком) | `bc` (велосипед) | `tv` (такси). Для рейсов нужен `auto`, но не блокируй остальные — просто сохрани.
- Если `rtext` нет, а есть `um=` — это ссылка на сохранённую карту, а не маршрут: покажи ошибку «Это ссылка на карту, а не на маршрут. Постройте маршрут и нажмите "Поделиться" → "Ссылка"».
- Бейджи/мусор вокруг ссылки — возможны: выдёргивай `rtext=([^&\s]+)` регэкспом.

## Что сделать в коде платформы (kontur-1c)

1. **Схема БД** (`prisma/schema.prisma`, модель `TransportRequest`) — два новых поля:
   ```prisma
   routeLink      String?   // исходная ссылка Яндекс.Карт
   routeWaypoints String?   // JSON: [[lat,lng],[lat,lng],...] по порядку следования
   ```
   Применить `bun run db:push` (миграция не нужна, демо-стенд).

2. **Кнопка «Построить маршрут»** на карточке/просмотре заявки (там, где диспетчер работает с заявкой — RequestsScreen или DispatchScreen):
   - открывает `https://yandex.ru/maps/?rtext=<lat1>%2C<lon1>~<lat2>%2C<lon2>&rtt=auto` в новой вкладке (`target="_blank" rel="noopener"`);
   - координаты — из `fromLocation` / `toLocation` заявки (в модели `Location` есть `lat`, `lon`); если у заявки уже сохранён `routeWaypoints` — открыть ссылку со ВСЕМИ точками, чтобы диспетчер продолжал править;
   - подсказка рядом: «Постройте маршрут и нажмите "Поделиться" → "Ссылка", затем вставьте её ниже».

3. **Поле вставки + разбор**: input для ссылки + кнопка «Разобрать ссылку» → парсишь `rtext` → `routeWaypoints`, показываешь «Маршрут: N точек» (и мини-список координат), сохраняешь оба поля в заявку. Кривая ссылка — человеческая ошибка, заявка не блокируется.

4. **GET /api/1c/orders** — в каждый элемент `orders[]` добавь два поля (контракт приложения водителя):
   ```json
   {
     "number": "ЗК-2026/1075",
     "...": "все существующие поля без изменений",
     "routeLink": "https://yandex.ru/maps/?rtext=...&rtt=auto",
     "routeWaypoints": [ { "lat": 55.75393, "lng": 37.620795 }, { "lat": 59.931123, "lng": 30.360932 } ]
   }
   ```
   ВАЖНО: `routeWaypoints` — массив объектов `{ lat, lng }` (именно lat/lng, не [lat,lng] и не {latitude,...}). Нет маршрута — `null` в обоих полях. Остальные поля не трогай.

5. **Журнал**: факт вставки маршрута запиши в журнал регистрации (REQUEST_ROUTE_SET или аналогичное событие) — по канонам фазы 1.

Затем заявка проверяется в приложении водителя (порт 3000): «Взять заявку» → маршрут построится по точкам (~706 км МСК→СПБ, баннеры манёвров по улицам Москвы). Эту часть делает заказчик сам — тебе достаточно корректного JSON в /api/1c/orders.

## Не делай

- Не меняй существующие поля контракта /api/1c/orders и обратный канал POST — приложение водителя на них завязано.
- Не тяни никаких API-ключей Яндекса: маршрут строится руками в Яндекс.Картах, платформа только разбирает ссылку (лицензионное ограничение проекта — без Yandex API).
- Не начинай качать тайлы или строить геометрию дороги на стороне платформы — приложение водителя строит маршрут сам (OSRM по точкам).
