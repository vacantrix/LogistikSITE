# Нейропроверка документов (OCR)

OCR — локальный конвейер на серверах АЭМЗ. Облачных моделей нет: фото
документов не покидают контур завода.

```
браузер → сжатие (sharp, 2400 px, JPEG 92%)
       → платформа: Document(dataUri)
       → OCR-шлюз :3020 (очередь, таймауты, кэш)
       → PaddleOCR :3031 (PP-OCRv5/v6, только 127.0.0.1)
       → поля + уверенности
       → src/lib/verify.ts → PASSED / REUPLOAD / REJECTED / MANUAL
```

## 1. Компоненты

| Компонент | Порт | Ответственность |
|---|---:|---|
| Платформа (`src/lib/ocr-service.ts`) | 3000 | очередь, параллельность, таймаут, кэш, вызов шлюза |
| OCR-шлюз (`mini-services/ocr-service`) | 3020 | приём `dataUri`, сжатие, `X-OCR-Token`, проксирование |
| PaddleOCR (`mini-services/paddle-ocr`) | 3031 | детекция строк, распознавание, поля, уверенности |

Шлюз и движок слушают только `127.0.0.1`. Наружу открыт только Caddy.

## 2. Документы

| Документ | Поля | Независимые подтверждения |
|---|---|---|
| Паспорт, страница с фото | ФИО, дата и место рождения, серия/номер, дата выдачи, код подразделения | обе копии номера на полях совпали |
| Паспорт, регистрация | дата, код подразделения, адрес | — |
| Водительское удостоверение | ФИО, дата рождения, номер, категории, даты выдачи/окончания | латинская строка, повторное чтение категорий, срок = выдача + 10 лет |
| СТС, лицевая сторона | госномер (в т. ч. прицепа «АВ1234 23»), VIN, марка, номер СТС | — |
| СТС, оборот | собственник, лизингодатель, срок временного учёта, номер | — |
| Доверенность (М-2 и свободная форма) | номер, даты, кто выдал, представитель | — |

Правила сверки с заявкой, пороги и статусы — на платформе
(`src/lib/verify.ts`), не в OCR-сервисе. Сервис только читает документ.

## 3. Очередь и параллельность

Очередь общая для всех пользователей. Одновременно обрабатывается не больше
`nnParallel` фото (настройка «Нейросеть» → «Максимум фото в обработке»,
подбирается под VRAM/память машины). Остальные ждут. При пакетной загрузке
ставьте 1–2: каждое следующее фото ждёт все предыдущие.

Таймауты:

- шлюз — до 170 с на документ (`PADDLE_TIMEOUT_MS`);
- платформа — 180 с (настройка «Таймаут распознавания»);
- первый запрос дольше: модель грузится 5–20 с.

Повторный скан ищется в кэше по хэшу. Если OCR недоступен, документ остаётся
`PENDING`/`MANUAL` и проверяется повторно; фиктивный результат не
подставляется.

## 4. Модели

По умолчанию: `PP-OCRv5_server_det` + `eslav_PP-OCRv5_mobile_rec` — сильнейшая
кириллическая связка PaddleOCR. На стенде NN включён набор PP-OCRv6:
`PP-OCRv6_medium_det` + `metrika-labs/PP-OCRv6_medium_rec_cyrillic`
(локальная папка модели).

Переменные:

| Переменная | Смысл |
|---|---|
| `PADDLE_OCR_PORT` | порт движка (3031) |
| `OCR_SERVICE_TOKEN` | общий токен платформы, шлюза и движка |
| `OCR_DET_MODEL`, `OCR_REC_MODEL` | имена моделей из зоопарка |
| `OCR_DET_MODEL_DIR`, `OCR_REC_MODEL_DIR` | локальные папки моделей вне зоопарка |
| `OCR_LOW_MEMORY` | `1` — процесс на документ, экономия памяти |
| `OCR_DET_MAX_SIDE`, `OCR_DET_AREA` | лимиты кадра и площади детекции |
| `OCR_LEX_TAU` | порог словарной правки |

Модели и venv лежат рядом с сервисом (`.models`, `.venv`) и не коммитятся.
Скачанные модели остаются на сервере: дальше сервис работает без интернета.
Не держите их в `%TEMP%` — автоочистка Windows удалит.

## 5. Точность и устойчивость

- **Словарь** (`lexicon.py`): регионы, города, штампы «Кем выдан», адреса,
  имена и отчества. Слово меняется на близкое словарное, только если
  нейросеть допускала такое чтение и правдоподобие ухудшается не больше
  `OCR_LEX_TAU`.
- **Наклон** фото выпрямляется по средней линии строк.
- **Поворот** (боком/вверх ногами) определяется голосованием строк, кадр
  поворачивается и читается ещё раз.
- **Память**: пиковая детекция ≈ 4–5 ГБ на Мпиксель; при свободной памяти
  < 6 ГБ включается режим короткоживущего процесса и «лестница» уменьшения
  кадра. Процесс, убитый OOM, повторяется со следующей ступенью.

## 6. Запуск

```powershell
# движок
cd mini-services\paddle-ocr
.\.venv\Scripts\python server.py        # 3031
# или
powershell -File .\start-service.ps1 -Port 3031

# шлюз
cd mini-services\ocr-service
bun install
bun run dev                             # 3020
```

Проверка: `GET http://127.0.0.1:3031/health`,
`GET http://127.0.0.1:3020/health` (с `X-OCR-Token`, если задан).

## 7. Приватность

- Реальные паспорта, ВУ и СТС не коммитятся и не пересылаются в чат.
- `tools/ocr-probe/samples_real/`, `out_real/`, `requests/` — локальные,
  исключены `.gitignore`.
- Синтетические образцы (`make_samples.py`) содержат вымышленные данные и
  штамп «ОБРАЗЕЦ».
- Сканы хранятся на серверах АЭМЗ; доступ к файлам — по токену с проверкой
  прав.

Подробно о ручных пробах — `tools/ocr-probe/README.md`.
