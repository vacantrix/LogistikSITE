# Маршруты Яндекс.Карт

Офис строит маршрут в Яндекс.Картах и вставляет ссылку в рейс. Платформа
сохраняет **точную геометрию** этой ссылки и автоматически доставляет её
водителю. OSRM — только резерв, когда линии Яндекса нет.

## 1. Ссылка

Логист использует «Поделиться» → «Ссылка». В ссылке есть `rtext` — точки
маршрута в порядке объезда:

```
https://yandex.ru/maps/?rtext=44.8721,38.1612~45.0355,38.9753&rtt=auto
```

`rtext=широта,долгота~широта,долгота`. Платформа разбирает его регэкспом,
поэтому текст вокруг ссылки не мешает.

## 2. Точная геометрия

Публичная страница Яндекс.Карт с `rtext` содержит готовый ответ
маршрутизатора — `routerResponse.routes[0].coordinates`. Это та самая линия,
которую видит логист, без ключей API и без пересчёта.

`src/lib/kontur/yandex-route.ts`:

1. `parseYandexRouteLink()` — проверяет ссылку и достаёт точки;
2. `fetchYandexRoadRoute()` — запрашивает страницу, вырезает JSON
   `routerResponse`, парсит координаты;
3. `geoJsonFromCoords()` — собирает `LineString`;
4. возвращает `{ coords, distanceM, durationS, source: 'yandex' }`.

Если страница недоступна, вернётся `null` — вызывающий код строит OSRM.

## 3. Что сохраняется

В `DispatchLeg`:

| Поле | Содержимое |
|---|---|
| `routeGeometry` | GeoJSON `LineString`, координаты `[lng, lat]` |
| `routeWaypoints` | JSON-массив `{lat,lng}` в порядке объезда |
| `routeDistanceM` | длина, метры |
| `routeDurationS` | время, секунды |
| `routeSource` | `yandex` или `osrm` |
| `routeLink` | исходная ссылка |

`driver-bridge.ts` отправляет в модуль водителя снимок `TRIP` с
`routeGeoJson`, `routeWaypointsJson`, `routeDistanceM`, `routeDurationS` и
событие `ROUTE_SET`.

## 4. Приоритет на карте водителя

```
routeSource === 'yandex'  → строим офисную линию, OSRM не вызываем
routeSource === 'osrm'    → линия по точкам, подпись «линия по точкам»
нет геометрии             → OSRM по waypoints; если и он недоступен — прямая
```

При `routeSource=yandex` OSRM не строится и не подменяет маршрут. Это
закреплено в `driver/src/components/azmz/map-screen.tsx` и проверено на
стенде.

## 5. Проверенный пример

Рейс `ЗК-1042`, Абинск (АЭМЗ) → Краснодар, Ростовское ш., 14:

- `routeSource=yandex`;
- 2 355 координат;
- 94 394 м;
- 5 900 с;
- PWA показывает 94 км и полную оранжевую линию.

## 6. OSRM

`fetchRoadRoute()` перебирает адреса:

1. `OSRM_BASE_URL`, если задан;
2. `https://vacantrix.ru/osrm/route/v1/driving`;
3. `https://router.project-osrm.org/route/v1/driving`.

Таймаут — 12 с на попытку. Профиль — `driving`. Точки передаются по порядку,
поэтому даже резервная линия идёт через все адреса офиса.

## 7. Ограничения

- Разметка страницы Яндекса может измениться; тогда сработает OSRM-резерв,
  а в интерфейсе будет честная подпись.
- Координаты Яндекса — в порядке `[lng, lat]` для GeoJSON; не перепутайте при
  ручной правке.
- Ссылка должна содержать `rtext`; ссылка на точку или организацию не
  является маршрутом.
- Платформа не использует платный API Яндекса и не требует ключа.
