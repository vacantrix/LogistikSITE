# docs/ — документация интеграций

Материалы внешних интеграций платформы. Эта папка публикуется на GitHub Pages
(схема публикации — в `1c/simulator/instructions.md`), поэтому содержит только
материалы 1С, без кода платформы и секретов.

| Папка/файл | Содержание |
|---|---|
| `1c/README.md` | **главное**: схема обмена 1С ↔ платформа, поля, curl-примеры, развёртывание, подключение модулей |
| `1c/orders-form-web-logistic.bsl` | модуль формы «Заказы грузоотправителей»: кнопка «в Веб-Логистик», отправка рейсов, приём статусов |
| `1c/send-request-form-module.bsl` | модуль отдельного документа «Заявка на перевозку» |
| `1c/onec-check.mjs` | проверка обмена с сервера или своего ПК, без 1С и браузера |
| `1c/simulator/` | HTML-симулятор формы 1С «Такси» для GitHub Pages + инструкция публикации |
| `.nojekyll` | GitHub Pages: отдавать файлы как есть |

Установленная копия симулятора, которую раздаёт сама платформа по `/1c-simulator/`,
лежит в `public/1c-simulator/` (после правки исходника в `1c/simulator/index.html`
скопируйте файл туда ещё раз — см. `1c/README.md`).

Код шины 1С на стороне платформы: `src/app/api/integration/1c/*`, `src/lib/onec.ts`.
