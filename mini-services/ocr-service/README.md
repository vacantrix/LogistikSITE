# OCR-шлюз (порт 3020)

Самохостед-микросервис распознавания: платформа передаёт ему скан (dataUri), шлюз
отправляет его движку PaddleOCR на ПК нейросети АЭМЗ (выделенная машина с GPU) и возвращает
поля с уверенностями. Слушает **только 127.0.0.1** — снаружи недоступен.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус шлюза: версия, счётчик распознанных, аптайм, активный движок |
| GET | `/upstream` | живая проверка движка (лёгкий GET `/health` на ПК нейросети АЭМЗ, без OCR) |
| POST | `/ocr` | `{ type, dataUri } → { ok, ocr, chain }`; `422` — вид документа без шаблона, `503` — движок недоступен |

Авторизация — заголовок `X-OCR-Token` (= `OCR_SERVICE_TOKEN`).

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `OCR_PORT` | `3020` | порт шлюза |
| `PADDLE_OCR_URL` | `http://127.0.0.1:3031/ocr` | адрес движка (ПК нейросети АЭМЗ) |
| `OCR_SERVICE_TOKEN` | — | входной токен шлюза |
| `PADDLE_OCR_TOKEN` | = `OCR_SERVICE_TOKEN` | токен наружу (к движку) |

Таймаут одного документа — до 170 с (движок распознаёт ~2,3 с/док; первый запрос
ещё и грузит модель). Очередь и параллельность держит платформа
(`src/lib/ocr-service.ts`): настройки «Нейросеть» применяются до вызова шлюза.

## Запуск

```bash
cd mini-services/ocr-service
bun install
bun run dev    # :3020
```

Проверка: `curl http://127.0.0.1:3020/health` (с токеном, если задан).
