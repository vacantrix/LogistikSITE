# drivemobile — АЗМЗ Логистика

Репозиторий сквозной связки **«диспетчерская платформа «Контур 1С» ↔ приложение водителя**.

| Компонент | Путь | Порт | Что это |
|---|---|---|---|
| **Приложение водителя** (PWA) | `/` (корень репо) | **3000** | Next.js 16 + MapLibre: заявки из 1С, предрейсовая фотофиксация, навигация, пометки, офлайн-карта. Устанавливается на телефон (PWA/APK) |
| **Платформа «Контур 1С»** | `kontur-1c/` | **3001** | Эмулятор учётного контура 1С: справочники, заявки, диспетчерская, маршрутные листы, план обмена |
| Легаси-каркас (Kotlin) | `download/azmz-karkas/` | — | Справочный каркас Android+Spring Boot, из которого выросла архитектура. Не участвует в запуске |

```
┌─────────────────────────┐   X-Driver-Id    ┌──────────────────────────┐
│  Приложение водителя    │ ───────────────► │  Платформа «Контур 1С»   │
│  :3000 (PWA, офлайн)    │  GET /api/1c/orders (заявки + маршрут)      │  :3001 (диспетчерская)
│                         │                  │                          │
│  заявки → фото → рейс   │ ◄─────────────── │  заявки ← сбыт           │
│  карта + GPS + пометки  │  POST /api/1c/orders (ACCEPT, PRETRIP_STEP, │  назначение ← диспетчер │
│  история рейсов         │   START_ROUTE, COMPLETE_TRIP + фото)        │  маршрут ← ссылка Яндекс.Карт │
└─────────────────────────┘                  └──────────────────────────┘
        │ прокси /api/1c/orders (KONTUR_1C_URL, по умолчанию http://127.0.0.1:3001)
        └── свой демо-бэкенд синхронизации: /api/driver/v1/sync/* (outbox, курсор), /api/maptiles/*
```

Единственная точка связи — тонкий прокси `/api/1c/orders` на стороне приложения (ТЗ 10.2).
При подключении реальной 1С меняется только `KONTUR_1C_URL` — контракты идентичны.

## Быстрый старт (локальная машина)

Нужен [Bun](https://bun.sh) ≥ 1.2 (или Node ≥ 22 + npm — команды аналогичны).

### 1. Платформа «Контур 1С» (:3001)

```bash
cd kontur-1c
bun install                 # свои node_modules (не делит с приложением!)
bun run db:push             # схема Prisma -> SQLite db/custom.db
bun run db:seed             # демо-данные: 15 ТС, 12 водителей, 6 заявок
bun run dev                 # http://localhost:3001
```

После сида демо-водитель: **Иванов Сергей Петрович**, ключ приложения (`X-Driver-Id`)
`d1111111-1111-4111-8111-111111111111`. UUID-ы записей регенерируются каждым сидом.

### 2. Приложение водителя (:3000)

```bash
cd <корень репо>
bun install
bun run db:push             # схема демо-бэкенда -> db/custom.db
bun run dev                 # http://localhost:3000
```

Демо-журнал (рейс Z-1067, пометки, чат) засеется сам при первом обращении к API.

> Порты и пути к базам зашиты в скрипты `dev`/`start`/`db:*` (переменная `DATABASE_URL`
> в командах перекрывает окружение — приложения в подпапках не конфликтуют).
> Прод-сборка: `bun run build && bun run start` у каждого приложения.

### 3. Проверка связки за 2 минуты

1. Откройте **платформу** http://localhost:3001 → «Склад и доставка» → «Маршрутные листы».
2. Выберите заявку в пуле → **«Построить маршрут»** (откроет Яндекс.Карты с пунктами заявки)
   → в Яндекс.Картах «Поделиться → Ссылка» → вставьте в поле «Ссылка на маршрут» →
   **«Разобрать ссылку»**. У заявки появится бейдж «маршрут: N точек».
3. Назначьте ТС и водителя (демо-водитель — Иванов С. П.) → **«Назначить — провести документ»**.
4. Откройте **приложение** http://localhost:3000 на телефоне/в девтулзе мобильного вида:
   сплэш-анимация → окно заявки (с бейджем «Маршрут из Яндекс.Карт · N точек») →
   **«Взять заявку»** → маршрут по дорогам (OSRM по точкам ссылки) →
   **предрейсовая фотофиксация: автомобиль спереди, прицеп сзади, селфи с документами** →
   **«Начать маршрут»** → карта с точками «Погрузка / Точка / Выгрузка».
5. На платформе (журнал регистрации и «Рейсы») видны все действия водителя,
   фото предрейсового осмотра — в карточке заявки.

## Установка на телефон

- **Android:** в приложении кнопка «Установить приложение» скачивает настоящий APK
  (`/azmz-driver.apk`, обёртка над PWA). Либо Chrome → «Установить приложение»
  (PWA: manifest + service worker, полноэкранный режим, офлайн-карта).
- **iOS:** Safari → «Поделиться» → «На экран “Домой”».
- Для установки с другого устройства приложение должно быть доступно по HTTPS
  (например, через `cloudflared tunnel --url http://localhost:3000`).

## Контракты интеграции

**GET `/api/1c/orders`** (заголовок `X-Driver-Id` — ключ водителя) — заявки водителя:

```jsonc
{
  "orders": [{
    "number": "ЗК-2026/1074", "externalId": "…", "client": "ООО «Донсталь»",
    "cargo": "Металлопрокат листовой, 2 шт.", "weightT": 20.2,
    "fromLabel": "Абинск, пл. АЗМЗ", "toLabel": "Ростов-на-Дону, склад №4",
    "loadingAt": "…", "unloadingWindow": "…", "vehicle": "МАЗ 6312 · В 789 СА 23",
    "trailer": "—", "docs": ["ТТН", "…"], "distanceKm": 347, "durationMin": 330,
    "status": "ASSIGNED", "assignedBy": "Диспетчер Е. Крылова",
    "routeLink": "https://yandex.ru/maps/?rtext=…&rtt=auto",   // ссылка диспетчера
    "routeWaypoints": [{ "lat": 44.8682, "lng": 38.157 }, …]    // точки из ссылки
  }],
  "eventLog": [{ "at": "…", "orderId": "ЗК-2026/1074", "action": "ACCEPT" }]
}
```

**POST `/api/1c/orders`** — обратный канал (идемпотентен):

```jsonc
{ "orderId": "ЗК-2026/1074", "action": "ACCEPT" }
{ "orderId": "ЗК-2026/1074", "action": "PRETRIP_STEP", "stepId": "veh_front", "photoDataUrl": "data:image/jpeg;base64,…" }
{ "orderId": "ЗК-2026/1074", "action": "START_ROUTE" }
{ "orderId": "ЗК-2026/1074", "action": "COMPLETE_TRIP" }
```

Шаги фотофиксации (единые на обеих сторонах): `veh_front` (автомобиль спереди),
`trailer_rear` (прицеп сзади), `selfie_docs` (селфи с документами).
`START_ROUTE` отклоняется (409), пока не закрыты все три шага.

**Разбор ссылки маршрута** (платформа): `POST /api/office/requests/{id}/route` `{ "link": "https://yandex.ru/maps/?rtext=…&rtt=auto" }`
→ `routeLink` + `routeWaypoints` в заявку; кривые ссылки дают 400 с человеческой причиной,
отказ пишется в журнал регистрации (`ROUTE_ATTACH_REJECTED`).

## Переменные окружения

| Приложение | Переменная | По умолчанию | Смысл |
|---|---|---|---|
| водитель | `KONTUR_1C_URL` | `http://127.0.0.1:3001` | адрес платформы для прокси `/api/1c/orders` |
| водитель | `DATABASE_URL` | `file:../db/custom.db` | демо-бэкенд (скрипты задают сами) |
| платформа | `DATABASE_URL` | `file:../db/custom.db` | SQLite демо / PostgreSQL стенда |
| платформа | `GIS2_API_KEY` | — | ключ 2ГИС Routing API (без него — заглушка-прямая) |
| платформа | `DRIVER_APP_ORIGIN` | `*` | CORS для приложения водителя |

## Сценарий водителя (воркфлоу заявки)

```
сплэш → окно выбора заявки → «Взять заявку»
   → маршрут по дорогам (OSRM по точкам из ссылки; без сети — демо-геометрия А-146)
   → ЭТАП 1: предрейсовая фотофиксация (3 фото) — «Начать маршрут» заблокирован до всех фото
   → рейс: карта-фон, точки «Погрузка/Выгрузка», манёвры, пробки, пометки, офис-чат
   → прибытие → «Завершить рейс» → заявка в «Истории» (точки загрузки/выгрузки видны в записи)
```

Активная заявка (рейс идёт) — приложение после запуска сразу открывает карту.
Заявки опрашиваются каждые 10 с: назначение диспетчером появляется без перезапуска.

## Структура репозитория

```
src/                     приложение водителя (Next.js App Router)
  components/azmz/         экраны: сплэш, заявки, карта, рейс, история, пометки…
  components/pwa/          регистрация SW, кнопка установки (APK)
  lib/                     стор (zustand+persist), синхронизация, парсер Яндекс-ссылок
  app/api/                 прокси 1С, демо-бэкенд синхронизации, тайлы карты
public/                   manifest.webmanifest, sw.js (v7), иконки, azmz-driver.apk
kontur-1c/               платформа «Контур 1С» (отдельные node_modules и БД)
  src/lib/1c/              доменные сервисы: назначение, действия водителя, ссылки маршрутов
  src/app/api/office/      рабочие места: заявки, диспетчерская, журнал…
  src/app/api/1c/orders/   HTTP-сервис «1С» для приложения водителя
db/custom.db             SQLite демо-бэкенда приложения (зеедится автоматически)
download/azmz-karkas/    легаси-каркас Kotlin (Android + Spring Boot) — справочник
```

Подробности платформы: `kontur-1c/README.md` и `kontur-1c/HANDOFF.md`.
