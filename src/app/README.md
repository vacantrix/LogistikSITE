# src/app/ — маршруты платформы

Next.js App Router. Пользовательский интерфейс живёт на **единственном маршруте `/`**,
всё остальное — API.

```
app/
├── layout.tsx        корневой layout (шрифты, тема, Toaster)
├── globals.css       Tailwind 4 + стили платформы (markdown-view, sticky-таблицы…)
├── page.tsx          весь интерфейс: сессия → экран входа / вкладки по роли
├── instrumentation.ts  хук старта сервера (data-fixes)
└── api/              REST API — см. api/README.md
```

Почему один маршрут:

- роль берётся из сессии на клиенте (`/api/auth/me`) и переключает набор вкладок
  (`components/platform/shell.tsx`): админ/логист видят внутренний контур АЭМЗ,
  перевозчик — свой кабинет;
- переходы между разделами мгновенные (компоненты уже загружены), real-time события
  (`?XTransformPort=3003`) перечитывают данные без перезагрузки;
- 401 в любом вызове API возвращает на экран входа (`UNAUTHORIZED_EVENT`).
