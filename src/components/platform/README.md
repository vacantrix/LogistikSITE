# src/components/platform/ — экраны платформы

Экраны и блоки интерфейса «АЭМЗ Логистика». Состав вкладок по ролям задаёт
`shell.tsx` (`NAV_ALL`); страница `src/app/page.tsx` рендерит активную вкладку.

## Каркас

| Файл | Роль |
|---|---|
| `shell.tsx` | оболочка: шапка, меню по ролям, мобильный Tab Bar, меню аккаунта (мультиаккаунт) |
| `login-screen.tsx` | экран входа; блок «Демо-доступы» при заданном `NEXT_PUBLIC_DEMO_PASSWORD` |
| `common.tsx` | общий слой: `TabKey`, `TabProps`, `SectionHeader`, бейджи статусов, `LoadingBlock`/`ErrorBlock` |
| `perms.tsx` | провайдер гранулярных прав (`PermProvider`, `useCan`) |
| `notification-bell.tsx` | колокольчик уведомлений + favicon-бейдж |
| `logo-mark.tsx` | логотип платформы |

## Вкладки по ролям

| Вкладка (key) | Файл | Кто видит |
|---|---|---|
| Площадка заявок (`board`) | `board.tsx` | все роли: тендер, ставки, перебитие, выбор победителя |
| Черновики заявок (`drafts`) | `drafts.tsx` | логист, админ: ручные и «из 1С» (бейдж, `onecRef`) |
| Мои заявки (`my`) | `my-requests.tsx` | перевозчик: ставки, победы, экипаж, документы, «Отправить на проверку» |
| Подать документы (`apply`) | `apply.tsx` | перевозчик: пополнение базы — линии водителей, ТС, прицепы; Excel-шаблон |
| Назначение экипажей (`crew`) | `crew.tsx` | перевозчик: водитель + тягач + прицеп по выигранному тендеру |
| Проверка документов (`verify`) | `verification.tsx` | логист, админ: очередь комплектов, сверка полей, решения |
| Реестр заявок (`requests`) | `requests-registry.tsx` | логист, админ: все заявки, журнал по каждой |
| Реестр рейсов (`registry`) | `registry.tsx` | логист, админ: подтверждённые рейсы, карта доставки |
| Подписать ЭДО (`edo`) | `edo.tsx` | логист, админ, перевозчик: проформы, ЭТрН (SENT → SIGNED) |
| Справочники (`directory`) | `directories.tsx` | все роли: допущенные карточки, сроки документов |
| Отчёты (`reports`) | `reports.tsx` | логист, админ: сводные показатели + DOCX-выгрузка |
| Журнал событий (`journal`) | `journal.tsx` | логист, админ: техжурнал автопроверок и действий |
| **Нейросеть (`nn`)** | `neural.tsx` | **админ**: пропуск документов (параллельность, таймаут, кэш, сжатие), живой статус, тестовый прогон |
| **Настройки (`settings`)** | `settings.tsx` | **админ**: пороги уверенности и правила проверки полей |
| Профили и доступы (`admin-users`) | `admin-users.tsx` | админ: учётки, роли, должности |
| База данных (`admin-db`) | `admin-db.tsx` | админ: просмотр таблиц Prisma |
| **Архитектура (`arch`)** | `architecture.tsx` | **админ**: файловый проводник (открыть/править файл) + карта системы |
| Обращения (`support`) | `support.tsx` | все роли, чат двух сторон: перевозчик пишет в поддержку, логист/администрация отвечают и пишут перевозчику первыми |

## Диалоги и составные блоки

| Файл | Роль |
|---|---|
| `driver-intake.tsx` | нейромастер «Добавить водителя/ТС/прицеп»: фото → распознавание → карточка → допуск |
| `request-form.tsx` | форма создания заявки (логист), включая формат «Авто в порт» |
| `route-dialog.tsx` · `map-pick-dialog.tsx` · `delivery-map.tsx` | маршруты и карта (Leaflet) |
| `status-pipeline.tsx` | линия жизненного цикла заявки с подсказками |
| `proforma-fields.tsx` · `photo-steps.tsx` · `document-preview.tsx` · `scan-overlay.tsx` | проформы, пошаговые фото, предпросмотр сканов |
| `etrn-dialog.tsx` | формирование и отправка титула ЭТрН Т1 |
| `access-templates.tsx` · `access-views.tsx` · `access-sheet.tsx` · `access-ui.tsx` | система доступа: шаблоны должностей, матрица прав |
| `search-select.tsx` · `point-autocomplete.tsx` | поисковые селекты и подсказки адресов |
| `animated-rate.tsx` | анимация смены ставки в тендере |
