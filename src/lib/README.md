# src/lib/ — серверные правила и клиенты

Бизнес-логика платформы: маршруты `src/app/api/*` тонкие, правила живут здесь.

## Контур проверки документов

| Файл | Роль |
|---|---|
| `verify.ts` | движок автопроверки: качество фото → вид документа → распознавание → сверка полей с заявкой → вердикт PASSED / REUPLOAD / REJECTED / MANUAL |
| `ocr-service.ts` | клиент OCR-шлюза (:3020): пул одновременных распознаваний, таймаут на документ, кэш повторных сканов по хэшу, сжатие фото перед туннелем |
| `nn.ts` | настройки нейросети «пропуск документов» (таблица Setting): чтение с кэшем 5 с, валидация, сжатие sharp |
| `settings.ts` | пороги уверенности (confReupload/confReject/confAuto/minQuality), правила проверки, валидация форматов файлов |
| `ocr-jobs.ts` | реестр долгих нейроопераций в памяти процесса (для UI-индикаторов) |
| `photo-quality.ts` | быстрая проверка качества фото в браузере — до нейросети |
| `doc-issues.ts` | разбор флагов автопроверки для UI |

## Заявки, торги, справочники

| Файл | Роль |
|---|---|
| `requests.ts` | серверная логика заявок и торгов (транзакции SQLite, финализация истёкших тендеров) |
| `busy.ts` | «занят» ли экипаж/ТС в другом рейсе |
| `status.ts` | статусы, режимы, цвета, форматтеры — общий слой UI |
| `expiry.ts` | сроки действия документов справочников |
| `points.ts` | типы точек маршрута (завод, порт, склад) и иконки |
| `geo.ts` | расстояния «погрузка → назначение» |
| `dadata.ts` | DaData Suggest — подсказки адресов (ФИАС/ГАР) |
| `suggest.ts` | подсказки проформы: адрес регистрации, место рождения |
| `port-fields.ts` · `port-excel.ts` | формат «Авто в порт»: правила полей и Excel-выгрузка 19 колонок |

## Доступ и безопасность

| Файл | Роль |
|---|---|
| `auth.ts` | сессии (Bearer + подписанная кука), роли, `requireUser(...)` |
| `permissions.ts` | серверная проверка прав «контур → должность → исключения» |
| `perm-catalog.ts` | каталог прав (чистый модуль, используется и на клиенте) |
| `accounts.ts` | мультиаккаунт: реестр аккаунтов браузера, активная сессия вкладки |
